# 📱 Smart App Hub — ศูนย์รวมลิงก์สไตล์หน้าจอมือถือ (สำหรับ Google Apps Script & Web Apps)

เว็บแอปพลิเคชันสไตล์หน้าจอมือถือ (iOS / Modern Android Launcher) สำหรับรวบรวมลิงก์ระบบงานต่างๆ โดยเฉพาะ **Google Apps Script Web Apps** ที่ปกติจะไม่มีโลโก้ของตัวเอง ให้กลายเป็นไอคอนแอปพลิเคชันที่กดแล้วลิงก์ออกไปใช้งานได้ทันที พร้อม **ระบบหลังบ้าน (Admin Mode + Custom Icon Studio)** ที่ล็อกด้วยรหัส PIN

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **หน้าจอหลักสไตล์โทรศัพท์ (Phone Home Screen & Floating Dock)**
   - แสดงไอคอนแอปทรง Squircle (หรือเปลี่ยนเป็นวงกลม/สี่เหลี่ยมขอบมนได้) พร้อมเงาและแสงสะท้อนสไตล์ iOS
   - มีแถบ **Dock ด้านล่าง** แบบกระจกเบลอ (Glassmorphism) สำหรับปักหมุดแอปที่ใช้บ่อยที่สุด (สูงสุด 6 แอป)
   - กดที่ไอคอนเพื่อเปิดลิงก์ออกไปยังแท็บใหม่ทันที (`target="_blank"`)

2. **สตูดิโอปรับแต่งไอคอนหลังบ้าน (Custom Icon Studio)**
   - **โหมดคลังไอคอนสำเร็จรูป (100+ ไอคอน):** คัดสรรไอคอนสำหรับงานเอกสาร, ตาราง Sheets, ฟอร์ม, บัญชี, สต๊อกคลังสินค้า, HR, แจ้งซ่อม, AI ฯลฯ พร้อมเลือกสีพื้นหลังแบบไล่เฉด (Gradients) หรือกำหนดสีพื้น/สีเส้นไอคอนได้เองแบบอิสระ
   - **โหมดอัปโหลดรูปภาพ / ลิงก์รูป (Image Upload & URL):** อัปโหลดไฟล์รูปโลโก้จากเครื่อง (ย่อขนาดอัตโนมัติ + อัปโหลดขึ้น Supabase Storage bucket `app-icons`) หรือวาง Image URL ได้โดยตรง
   - **ตรวจจับลิงก์อัตโนมัติ:** เมื่อวางลิงก์ `script.google.com`, `docs.google.com/spreadsheets` หรือ `forms` ระบบจะแนะนำไอคอนและป้ายกำกับ (`GAS`, `Sheets`, `Form`) ให้อัตโนมัติ

3. **ลากสลับตำแหน่ง (Drag & Drop) & หมวดหมู่/โฟลเดอร์**
   - เมื่ออยู่ในโหมดแก้ไข (Admin Edit Mode) ไอคอนจะสั่นดุ๊กดิ๊ก (Jiggle Mode) สามารถลากสลับลำดับได้ทั้งบนคอมพิวเตอร์และหน้าจอสัมผัสมือถือ
   - แยกหมวดหมู่ด้านบน และสลับเป็น **มุมมองโฟลเดอร์ (Folder View)** ที่กดเปิดป๊อปอัปแสดงแอปข้างในได้เหมือนมือถือจริง

4. **ค้นหาด่วน (Spotlight Search) & รหัสล็อก PIN**
   - กดที่ช่องค้นหาหรือกดคีย์ลัด `Ctrl + K` / `Cmd + K` เพื่อพิมพ์ค้นหาชื่อแอปแล้วกด `Enter` เปิดลิงก์ได้ทันที
   - ล็อกหน้าจัดการหลังบ้านด้วย **รหัส PIN** (ค่าเริ่มต้นคือ `1234` เปลี่ยนได้ในหน้าตั้งค่า)

## 🚀 วิธีนำไปใช้งานบน Supabase + Vercel

### ขั้นตอนที่ 1: เตรียมฐานข้อมูลบน Supabase
1. สร้างโปรเจกต์ใหม่บน [Supabase](https://supabase.com/)
2. ไปที่เมนู **SQL Editor** แล้วคัดลอกคำสั่ง SQL จากไฟล์ [`supabase/schema.sql`](./supabase/schema.sql) (หรือกดปุ่ม **"คัดลอก SQL"** จากหน้าตั้งค่าในตัวเว็บ) ไปวางแล้วกด **Run**
   - คำสั่งนี้จะสร้างตาราง `categories`, `app_links`, `app_settings` และสร้าง Storage Bucket ชื่อ `app-icons` ให้พร้อมใช้งานทันที
3. ไปที่ **Project Settings -> API** เพื่อคัดลอกค่า `Project URL` และ `anon public key`

### ขั้นตอนที่ 2: นำขึ้นออนไลน์บน Vercel
1. อัปโหลดโค้ดชุดนี้ขึ้น GitHub Repository ของคุณ
2. เข้าเว็บ [Vercel](https://vercel.com/) กด **Add New Project** แล้วเลือก Repository นี้
3. ในส่วน **Environment Variables** บน Vercel ให้เพิ่มตัวแปรดังนี้:
   - `VITE_SUPABASE_URL` = URL โปรเจกต์ Supabase ของคุณ
   - `VITE_SUPABASE_ANON_KEY` = Anon Public Key ของโปรเจกต์ Supabase
   - `VITE_ADMIN_PIN` = รหัส PIN เริ่มต้นที่ต้องการ (เช่น `1234`)
4. กด **Deploy** ได้เลย! (มีไฟล์ [`vercel.json`](./vercel.json) ตั้งค่าไว้ให้เรียบร้อยแล้ว)

> **หมายเหตุ:** คุณสามารถกรอกค่า `Supabase URL` และ `Anon Key` ผ่านหน้าจอ **"ตั้งค่าระบบหลังบ้าน -> เชื่อมต่อ Supabase & Vercel"** บนหน้าเว็บได้โดยตรงเช่นกัน และมีปุ่มกดส่งข้อมูลจากเครื่องขึ้น Supabase ได้ในคลิกเดียว

## 💻 การรันบนเครื่องคอมพิวเตอร์ (Local Development)

```bash
# ติดตั้งไลบรารี
npm install

# รันเซิร์ฟเวอร์พัฒนา
npm run dev

# ตรวจสอบการ Build สำหรับ Production
npm run build

# รันชุดทดสอบ Automated Tests
npm test
```
